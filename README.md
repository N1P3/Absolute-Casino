## Założenie projektu

Tematem projektu jest internetowe kasyno. Dostępne będą różne gry typu "slots", jak i klasyczne gry takie jak ruletka czy blackjack. Walutą w grze będa wirtualne punkty, które gracz będzie wydawał na zakłady. Wyniki gier będą determinowane za pomocą algorytmów wykorzystujących RNG, zapewniających sprawiedliwość oraz zgodność z prawem.

## Technologie

### Backend:

- Java
- Spring Boot
- Hibernate
- PostgreSQL

### Frontend:

- Typescript
- React

## Uruchomienie projektu

#### Frontend:

- `cd frontend`
- `bun install`
- `bun run dev`
